## Reading this page

The three sections are three different claims. The gate says the migration is complete in the
sense the tracker defines. The test table says the code that replaced JavaParser executes and
asserts, on this machine, in this build. The benchmarks say what the replacement costs.
A number missing from any of them is stated as missing rather than left at zero, because a
report that reads as complete when it is not is the failure mode this whole phase is about.
