# Phase 2: Core AST Utilities

## Overview

This directory contains core AST traversal and manipulation utilities that form the foundation for all code generation and validation tools.

## Files

### util/
Contains utility classes:
- `NodeTraversal.java` - AST traversal utilities
- `AstPrinter.java` - Source printing utilities
- `SourceManipulation.java` - Text manipulation utilities
- `TypeUtils.java` - Type utilities

### tests/
Unit tests for all utility classes.
