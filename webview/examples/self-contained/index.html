One file that can navigate your project

This page is a self-contained project navigator: markup, styling, script and syntax highlighting all live in this single .html file. Open it inside WebView Explorer (right-click the file → Open in WebView Explorer, or Ctrl+Alt+Shift+W) and every link below opens the real file at the real line. Open it in a browser and the same clicks fall back to the IDE's loopback HTTP bridge, or copy path:line to the clipboard.

It mixes the two kinds of page a project navigator always ends up with: manual prose that a human maintains (this section, How a click works) and generated material a build step owns (Entity reference, Source files). Both are sections of one document with one navigation shell, one stylesheet and one script — so there is exactly one place where a link contract, a theme or a fallback rule can be wrong.

Nothing here is hard-coded to a machine. data-link-base="../../.." on <body> is the only thing that knows where the project root is, and it is relative. Clone the repository elsewhere, switch branches, or move the page, and the links still land.

How a click works

The host contract is one function and two attributes. The page puts a location on an element; the IDE webview injects the function that opens it. The page never calls the function unguarded, because an undefined window.openFile throws a TypeError inside a click handler and silently kills every later click in the page. 

// 1. the IDE webview injected this after the page loaded
if (typeof window.openFile === 'function') {
  window.openFile('src/main/java/com/example/Person.java', 14, 1);   // line, column (1-based)
}

// 2. no function? a loopback HTTP bridge may be listening instead.
//    A hidden iframe needs no CORS grant, so it works from a file:// page.
const frame = document.createElement('iframe');
frame.style.display = 'none';
frame.src = `http://127.0.0.1:18881/open?filePath=${encodeURIComponent(abs)}&line=14&column=1`;
document.body.appendChild(frame);

// 3. neither? put the location where the user can use it. Never render a dead link.
navigator.clipboard?.writeText('src/main/java/com/example/Person.java:14');

AttributeRequiredMeaning

There is no data-column in the API. Nothing in this repository's pages needs a column other than 1. The handler passes the column to window.openFile directly if a page wants one.

JavaScript source.js

// grammars/javascript.js — scope source.js, no external grammar dependencies
const BRIDGE_PORT = 18881;

/** Feature-detect the injected function before you call it. */
function openInIde(relativePath, line = 1) {
  const target = new URL(relativePath, document.baseURI).pathname;

  if (typeof window.openFile === 'function') {
    window.openFile(target, line, 1);
    return 'injected';
  }
  if (BRIDGE_PORT > 0) {
    const frame = document.createElement('iframe');
    frame.src = `http://127.0.0.1:${BRIDGE_PORT}/open?filePath=${encodeURIComponent(target)}&line=${line}`;
    document.body.appendChild(frame);
    return 'bridge';
  }
  navigator.clipboard.writeText(`${target}:${line}`);
  return 'clipboard';
}

document.addEventListener('click', (event) => {
  const link = event.target.closest('[data-open]');
  if (!link) return;
  event.preventDefault();
  openInIde(link.dataset.open, Number(link.dataset.line) || 1);   // 0 and NaN mean line 1
});

Java source.java

// grammars/java.js — scope source.java, no external grammar dependencies
package hr.hrg.jetbrains.webview.bridge;

import java.nio.file.Path;
import java.util.Optional;

/**
 * One place where a path becomes an open editor, so the injected function and
 * the HTTP fallback cannot drift apart.
 */
public final class NavigatorService {

    private static final int MAX_LINE_LENGTH = 100_000;

    /** Resolve {@code filePath} against the project and open it at a 1-based line. */
    public Optional<Integer> open(String filePath, int line, int column) {
        Path resolved = projectRoot.resolve(filePath).normalize();
        if (!resolved.startsWith(projectRoot)) {
            return Optional.empty();                 // refuse anything outside the project
        }
        int clamped = Math.max(1, Math.min(line, MAX_LINE_LENGTH));
        return openInEditor(resolved, clamped, Math.max(1, column));
    }
}

# Opening a file from a page

The contract is **one function** and *two attributes*.

- `window.openFile(path, line, column)` — injected by the IDE webview
- `data-open` / `data-line` — what the page puts on the element

> A dead-looking link is worse than a visible path string.

| Host | Port | Setting |
| --- | --- | --- |
| `webview/webview-jetbrains` | 18881 | `webview.explorer.port` |
| `webview/webview-vscode` | 18882 | `webviewExplorer.port` |

```js
window.openFile('src/main/java/Person.java', 14, 1);
```

See [the contract](../webview/doc/webview-link-api.md#L18) for the frozen details.
