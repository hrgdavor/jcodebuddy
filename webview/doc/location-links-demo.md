# Location links — the demo page

Open this document **through the webview host** (see [`../README.md`](../README.md), "Pointing at a place inside a
file"), and every link below should take the editor somewhere specific: a line, a range, a method, a region, a JSON key.
They are all real files in this repository, which is the point — the project dogfoods its own syntax.

Nothing here is special to this document: a link is an ordinary Markdown link whose target names a file and, after a
`#`, a place inside it. The page passes the target through; the host resolves the place.

## A line and a range

- [Navigator.java, line 42](webview/core/webview-core/src/main/java/hr/hrg/webview/core/Navigator.java#L42) — the plain
  spelling the contract always had.
- [Navigator.java, lines 42–58](webview/core/webview-core/src/main/java/hr/hrg/webview/core/Navigator.java#L42-L58) —
  a range, which the host selects as far as its editor can.

## A declaration, by name

- [the `open` method](webview/core/webview-core/src/main/java/hr/hrg/webview/core/Navigator.java#open) — a bare name is
  a declaration **or** a region directive of that name; the host tries the declaration, then the region.
- [its body only](webview/core/webview-core/src/main/java/hr/hrg/webview/core/Navigator.java#-open) — the `-` scope
  modifier, without the `region:` prefix, because the prefix is never required.
- [with its annotations](webview/core/webview-core/src/main/java/hr/hrg/webview/core/Navigator.java#+open) — `+`.
- [with its doc comment too](webview/core/webview-core/src/main/java/hr/hrg/webview/core/Navigator.java#++open) — `++`.

## A region, the way the resolver docs name one

`merge-java`'s resolver documentation links to regions of real tests with the inject spelling, so the same spelling
navigates here:

- [#region:replays-sticky-decision](merge-java/src/test/java/com/codebuddy/merge/MergeConflictResolverTest.java#region:replays-sticky-decision)
  — the region directive, found first, exactly as `@hrg/inject-examples`' code rule orders it.
- [#replays-sticky-decision](merge-java/src/test/java/com/codebuddy/merge/MergeConflictResolverTest.java#replays-sticky-decision)
  — the same region, written the short way.
- [#++replaysStickyDecision](merge-java/src/test/java/com/codebuddy/merge/MergeConflictResolverTest.java#++replaysStickyDecision)
  — a declaration with the widest scope, which lands on the declaration itself.

## A JSON key

`package.json`'s reference is its key paths, prefixed or not, because JSON has no comments to hang a region on:

- [region:name](package.json#region:name)
- [region:name,version](package.json#region:name,version) — a list, rendered as valid JSON by the injector, and one
  line here.
- [the bare spelling](package.json#name) — the file's type decides the rule, not the spelling.

## The inject marker form, and what happens to it

The documentation in this repository writes samples with a marker — a line that is nothing but a link to a real file,
with the fenced block after it holding that file's content. The location half of that marker is what navigates, so a
marker is both an include and a link:

    [merge-java/docs/resolvers/README.md](merge-java/docs/resolvers/README.md#region:add)

Here it is as a live link (not as a marker, so this demo is not regenerated by the injector) —
[merge-java's resolver docs, region `add`](merge-java/docs/resolvers/README.md#region:add).

## What has no location

Two links that should behave like ordinary links, because there is nothing for a host to resolve:

- [a heading in this document](#a-line-and-a-range) — an in-page anchor is the page's own business.
- [an external site](https://github.com/hrgdavor/inject-examples) — not a path at all.

## If a link does nothing

Then the page is not being shown by a host, or the host's bridge is not reachable. The ladder is in
[`../kit/doc/host-in-this-project.md`](../kit/doc/host-in-this-project.md): the injected `window.openFile` first, then
the host's HTTP bridge, then the clipboard. A `file://` page double-clicked from a file manager has no injected
function — open it through the IDE, or serve it from a host that is running.
